# 📝 Simple To-Do List App (Python & Kivy)

Aplikasi manajemen tugas (*To-Do List*) berbasis mobile sederhana yang dibangun menggunakan bahasa pemrograman **Python** dan *framework* **Kivy**. Project ini dibuat sebagai latihan pembuatan antarmuka pengguna (UI) serta logika dasar manipulasi data pada aplikasi mobile.

---

## 🚀 Fitur Utama

* **Tambah Tugas:** Menambahkan daftar tugas baru secara dinamis.
* **Hapus Tugas:** Menghapus tugas yang telah selesai dikerjakan.
* **Responsive UI:** Antarmuka yang mendukung *scrolling* saat daftar tugas mulai banyak.

---

## 🛠️ Tech Stack

* **Language:** Python 3.x
* **Framework:** Kivy
* **GUI Components:** `BoxLayout`, `ScrollView`, `TextInput`, `Button`, `Label`
